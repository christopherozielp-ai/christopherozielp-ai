## 🚀 Proyectos destacados

### CertFlow — Portal de Gestión de Certificaciones

Sistema full-stack para administrar procesos de certificación bajo normativas como TISAX, ISO 27001 e ISO 9001, con control de acceso basado en roles. Desarrollado como proyecto de estadía profesional, resolviendo la necesidad real de centralizar el seguimiento de certificaciones que antes se gestionaba de forma manual y dispersa.

- Tres roles diferenciados (Administrador, Auditor, Cliente), cada uno con permisos y vistas propias
- Backend en Spring Boot con control de acceso y notificaciones automáticas por correo
- Frontend en Angular 19 con componentes standalone y Tailwind CSS
- Dashboards con gráficas, búsqueda en tiempo real, historial de cambios y documentos imprimibles
